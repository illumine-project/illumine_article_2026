## GitHub and Overleaf

Same files, two views. They stay in step with Overleaf **Menu → Integrations → GitHub**:

- **Pull** from GitHub into Overleaf when `main` has new commits and you want the PDF to match.
- **Push** from Overleaf to GitHub when something was typed in Overleaf and should land here.

That push/pull is **manual**, not live. If you skip it, the PDF and GitHub can drift. If Overleaf reports a conflict, stop and tell Fred rather than forcing a merge.

**GitHub `main` is the copy we review.** Overleaf is how we compile it.

## How to contribute

**Default: GitHub issues and pull requests**, so comments stay visible to people who were not in Overleaf at the time.

1. **Issue first if you are unsure.** Open or reply on an issue (use [#2](https://github.com/illumine-project/illumine_article_2026/issues/2) if there is no better home). Say what you want to change and which section.
2. **Send text as a pull request.** Branch, edit the `.tex` files in this repo, PR against `main`. Keep PRs small (one section or one figure/table). After merge, **Pull** GitHub into Overleaf so the PDF updates.
3. **If you work in Overleaf anyway** (compile, tiny fix, figure placement), **Push** to GitHub when you are done. Do not leave a change only on Overleaf. Prefer a PR over pushing straight to `main` if the change is more than a typo.
4. **Figures and tables:** add the file in a PR (or Push, then open a PR) and note on the issue what it shows, which aim or facility, and whether it is public.
5. **Authors:** [Issue #1](https://github.com/illumine-project/illumine_article_2026/issues/1). Do not add or drop names in a silent TeX edit.
6. **No GitHub?** Email Fred a marked draft (section heading + text). He will open an issue or PR here.

Fred keeps the timeline and emails section owners when dates or owners change. There is a **short monthly tag-up** to unblock work; text and decisions still belong in an issue or PR.

Questions: ping Fred or comment on [Issue #2](https://github.com/illumine-project/illumine_article_2026/issues/2).
